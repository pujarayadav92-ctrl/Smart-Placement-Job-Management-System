# Smart Placement & Job Management System

A Java and MySQL based project designed to manage student placement activities.

## Features

- Student Management
- Company Management
- Job Management
- Application Management
- Interview Management

## Technologies Used

- Java
- MySQL
- JDBC
- Git and GitHub

## Requirements

- Java JDK
- MySQL Server
- MySQL Connector/J
- VS Code or another Java IDE

## How to Run

1. Clone or download this repository.
2. Configure your MySQL database and update the database connection settings.
3. Ensure the MySQL Connector/J JAR is available in the `lib` folder.
4. Open PowerShell in the project folder.
5. Compile the Java files:

   `javac -cp ".;lib\*" *.java`

6. Run the application:

   `java -cp ".;lib\*" Main`

## Project Goal

To practice Java programming, JDBC connectivity, MySQL database operations, and CRUD functionality through a placement management application.
